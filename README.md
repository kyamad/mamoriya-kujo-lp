# 迅速対応まもりや駆除 LP

合同会社K-TEC「迅速対応まもりや駆除」の静的ランディングページです。

## ローカル確認

プロジェクトルートから次を実行し、`http://127.0.0.1:8787/` を開きます。

```sh
npx -y http-server delivery/mamoriya-kujo -p 8787 -c-1
```

URLパラメータは不要です。採用済みデザインと表示修正は常時有効です。

### ファーストビュー比較案

クライアント確認用として、ファーストビューを3案切り替えられます。下部の視認性・写真・アコーディオン修正は全案共通です。

- A案（コピー優先の左右分割）：`/?approach=a`
- B案（中央集中型）：`/?approach=b`
- C案（緊急対応型の濃色パネル）：`/?approach=c`
- D案（A案のFV＋既存素材による本文の構成比較）：`/?approach=d`

D案は、FV → 保証概要・無料相談 → 簡単見積もり相談 → 高評価 → 症状 → プロへの相談 → 安心宣言 → キャンペーン → 繁殖・被害リスク → 対応害獣 → 地域・メディア紹介 → お客様の声 → 選ばれる理由 → 保証詳細 → 作業の流れ → FAQ → 害獣解説 → 会社概要の順です。
既存の文章・画像を再利用し、施工前後の実例、他社比較など素材のない要素は省略しています。見積もり相談は害獣と住宅の2問を選ぶ電話相談ガイドで、個人情報の送信や申し込みの自動受付は行いません。連絡先は既存の電話・LINEを利用します。並べ替えはD案のみで実行します。

D案のセクション2は「最長10年保証」「電話相談」の2段バナーです。人物・住宅はAdobe Stockの透かし入りプレビューを使用しています。素材番号と差し替え時の情報は `_mock/adobe-stock/PREVIEW-SOURCES.md` を参照してください。

パラメータなしの場合はA案を表示します。採用案決定後に不要な案を整理してください。

## 計測設定

GTMコンテナ `GTM-KQGQ6PK3` は、公開ホスト `kyamad.github.io` でのみ読み込まれます。ローカル環境や許可していないホストでは、GTM・Google広告・GA4の外部スクリプトは読み込まれません。設定は `/_mock/config.js` で管理します。

- `ANALYTICS_ENABLED`
- `ALLOWED_HOSTS`
- `GTM_PRIMARY_ID`
- `GOOGLE_ADS_ID`
- `GA4_MEASUREMENT_ID`

GTM内でGA4・Google広告を管理する場合、GTM以外のIDは空欄のままにして二重計測を避けてください。

## GitHub Pages

`main`ブランチへpushすると、`.github/workflows/pages.yml` が静的ファイルをGitHub Pagesへ公開します。現在はGitHub FreeでPagesを利用するため、リポジトリと閲覧URLの両方をPublicに設定しています。

Actions内では `scripts/build-pages.mjs` がGitHub Project Pages用のサブパスを付与し、`_site/` を生成して公開します。元のHTMLはローカルおよび独自ドメイン向けのルート相対パスを維持します。


D案の「プロへの相談」（旧セクション5）はスマホ幅700px以下のみ採用A案へ切り替わります。実装は `_mock/solution-mobile.js` / `.css`、PCは従来の表示を維持します。

### 2026-11-27: キャンペーン直後の被害解説

D案のみ、`.notice`の直後に`#damage-guide`を追加。
参考LPの「何かと後回しにしてしまう害獣被害ですが、」から相談を促す締めまでの構成を参考に、
放置への注意 → 再侵入と専門対策 → 対応害獣5種 → 通気口・屋根裏の糞・配線かじりの写真解説 → 既存の無料調査案内、の順で表示。
重複する締めの相談欄と既存の繁殖・被害リスク一覧は削除し、03 配線かじりの直後に既存の「一つでも気になることがあれば」の無料調査案内を配置。写真はAdobe Stock公式プレビュー（出典は`_mock/adobe-stock/PREVIEW-SOURCES.md`）。
説明テキストはHTML/CSSで合成し、小画面でも文字を調整可能にしています。
スマホ（700px以下）の4つの安心宣言は`padding-top:10pt`（約13.33px）。PCの余白は変更なし。

### 高評価の後の相談案内

D案の`.start`（首都圏サービス開始・高評価とメディア掲載）の直後、お客様の声の前に`#consultation-after-rating`を配置。業者選びの案内、24時間365日の受付案内、セクション2と同じ電話相談バナーを表示します。バナーは既存DOMを複製するため写真・電話番号・PC/スマホのデザインを共用します。回線状況の連携はないため「つながりやすい」等のリアルタイム表示は行いません。

### 業者比較

D案のお客様の声と選ばれる4つの理由の間に`#provider-comparison`を追加。料金、調査・見積もり、再発保証、対応スピード、対応エリアの5カードをタブ・前後ボタン・横スワイプで表示。自社は現行LPの基本7,000円〜／最長10年保証／最短30分／首都圏4都県を使用。根拠不明の競合A〜D社数値は転用せず、比較時の確認項目を並べています。

4つの理由・再発防止保証の後にも、既存の「信頼と実績の証！」から高評価・メディア掲載部分と相談バナーを再掲（`#trust-after-reasons` → `#consultation-after-reasons`）。サービス開始の導入は再掲せず、元の掲載箇所も維持。
