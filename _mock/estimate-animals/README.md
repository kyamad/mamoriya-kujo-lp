# 見積もり選択用の透過イラスト

Built-in image_gen により既存の v3-animal-illustrations の6画像を個別に背景透過。
元画像は保持し、このセクションのみで使用。

共通プロンプト（動物名だけ各ファイル名に置換）:
Use case: background-extraction. Edit target: the supplied animal illustration.
Remove ONLY the cream paper background and make it fully transparent with a real alpha channel.
Preserve the exact animal, pose, full body, colors, fine fur/whiskers/legs,
original illustration style and square framing. No new shadow, no text,
no checkerboard painted into image. This is a website selection icon.
Keep all animal parts intact.
